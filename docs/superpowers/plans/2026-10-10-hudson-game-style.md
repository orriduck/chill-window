# Hudson fantasy landscape, sole runtime style

User objective, 2026-10-10: retain the real-world Hudson map and interpret terrain, buildings, vegetation, water and lighting in a woodland/village fantasy game style inspired by World of Warcraft. This is the only Hudson experience. No compatibility UI, old/new comparisons or legacy query-selected alternatives.

## Sources and scope

Keep the bundled FRA/Amtrak route, USGS DEM, NLCD and OSM land/water masks, roads, source building anchors and station/platform geometry. Keep the passenger train/cabin, native Pause and preparation-gated focus/segment clocks, initial actual GPU upload/fence proof, route advance preparation/cache, F5 map and Escape return. Ground decoration samples the actual displayed DEM triangles. The narrow pre-existing rail-bed correction remains an engineering visualization; geographic hills are not invented.

Before implementation, the root task researched Blizzard's official WoW Classic restoration panel, Phillip Zhang's environment portfolio, and inspected Kenney Fantasy Town Kit `Sample.png`/`Preview.png`, Nature Kit `Sample.png`, and drummyfish's original painted grass/dirt PNGs. Source links and the exact observed/reference limitations are in `REFERENCES.md`. No extracted Blizzard assets are used.
