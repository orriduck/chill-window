## 真实浏览器检查

本地 Vite：`http://127.0.0.1:3001/`。Codex 浏览器默认 1280 × 720 视口。

- 从设置页 Board train 进入坐席车厢，确认高背软座、头枕套、扶手、金属腿、小桌、杯子、书、窗帘和行李架可辨认，无卧铺和爬梯。
- 晴日田野：可见连续作物地块、路基/栅栏和三层受光远丘。连续截图显示沿线物体相对固定窗框移动。修正地块穿插和植被侵入。
- 林间行驶：查看新增实例化树冠，能够与开阔田野区别。
- 湖畔：查看水面、岸线和远丘。雨天：查看暗化天空和玻璃上的雨点，前景软座未被雨点覆盖。夜间：查看星空、暗部山形、降低的车内亮度及阅读灯。
- 暂停/恢复：按钮和 HUD 切换为 Journey paused，恢复后继续行驶。
- 暂停时拖动转头：可见相邻坐席、行李架和车厢端门；Reset view 返回侧窗。
- F2 关闭软座组：座椅/桌面/窗帘消失，车体和窗外保留；全部恢复后重新显示。
- 从湖畔返回林地再返回田野：栅栏、电杆立即归位，无须等待前向循环。
- 浏览器采集的 error/warn 日志为空。

## 后续调整：靠窗乘客眼位

按用户反馈，默认眼位从走道中心移到靠窗坐垫上方。`core/PassengerView.ts` 为相机朝向和车厢定位提供同一组参数：车厢局部眼位 `(-1.45, -0.12, 1.0)`，与玻璃相距 1.0 个场景单位，朝窗外并略向列车前方看。保留原来的 FOV，不用缩放代替位置移动；窄屏也不再自动退到走道。实际尺度为场景单位，并非测量车型数据。

先在 F2 加入“乘客眼位”选择器，再检查默认靠窗视角、原走道对照、暂停时转头和 Reset view。近窗视角暴露出端墙伸到玻璃外的问题，已将端墙限制在车厢内部。桌面浏览器验证控件仍可点击、窗外没有端墙遮挡；没有运行自动测试，未核查窄屏和真机。
