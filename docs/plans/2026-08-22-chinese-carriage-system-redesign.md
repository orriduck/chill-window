# 中国列车车厢系统重构研究与设计边界

> **2026-09-04 方向更新：** 用户明确改为坐席列车。下文保留 08-22 研究历史；当前实现和验收以 `app/HANDOFF.md` 与 `docs/visual-checks/2026-09-04/README.md` 为准。

**历史状态：** 长途硬卧首版已实现并完成桌面浏览器视觉核查，模块拆分待继续  
**核查时间：** 2026-08-22  
**主要参考：** 藻蝦 AmanoShrimp 中国铁路旅行视频；具体 URL 与时间戳见 [`REFERENCES.md`](../../REFERENCES.md)。

## 结论

车厢需要系统重构。当前画面的问题不是缺少更多小物件，而是空间原型、模块边界和调试能力三者没有对齐：画面明确表现为“现代欧洲城际对坐包间”，而产品未来希望建立以中国列车为主要依据的车内与窗外体验。

用户已确认第一套目标原型采用**中国长途开放硬卧**。首版重点参考 Z27 次 25T 硬卧：每个窗口对应两侧三层铺的开放六铺单元，铺位向车厢内延伸，窗下小桌、攀爬踏板、护栏、铺位灯/插座和传统布帘共同建立结构。豪华动卧包厢、现代观景软座与展望车是后续独立原型，不应混入同一套几何。

## 证据与解释

### 可观察事实

- CR400AF-AE 动卧以暖色间接光、米白/浅棕软包、紧凑包厢窗、宽铺位和完全遮光窗帘建立夜间私密感。
- Z27 次 25T 硬卧明确展示半开放六铺单元、两侧三层铺、窗下小桌、金属踏板/护栏、铺位灯/电源与传统窗帘；它是首版普通长途硬卧的直接空间基线。
- 星光燕赵号将展望空间和售票座席分开；座席车同时提供四人卡座与面窗吧台座，并用大窗、高明度墙顶、木地板、局部彩色座椅和连续小尺度灯具组织空间。
- 西子号一等软座的窗墙明显有厚度，圆角大窗与面对面座席、桌面成组对应；风口、帘轨和窗胶条比装饰性造型更能说明真实车辆结构。
- 横贯中国视频里的地域变化由成组线索构成：地表色块、植被/农业、远山轮廓、铁路和电力设施、空气颜色、玻璃与窗帘；单独替换草地颜色不足以形成地点感。

### 设计解释

- “中国列车感”不应被压缩成红色、书法或纹样。首先要正确的是车体断面、窗墙厚度、座椅与窗口节距、桌面和行李/风口系统的机械逻辑。
- 车内原型与窗景路线应是两个可组合系统。车厢决定取景框、反射和近景遮挡；路线决定窗外的地域切片和运动层级。
- 不同车型需要独立布局，不应用一组座椅通过换色同时扮演软座、卧铺和展望车。

## 当前实现审视

- `app/src/engine/three/interior/WindowFrame.ts` 仍是大型单类；它同时负责车体外壳、三联窗口、六铺与卧具、桌面、端门、灯光、玻璃、雨滴、反射、HUD CanvasTexture、点击投影、程序化纹理、更新与销毁。
- 首版已把运行时空间从欧洲城际对坐包间替换为中国长途开放硬卧，但系统级模块拆分仍未完成。
- `ThreeCanvas.tsx` 已经提供正确的高层边界：外景先渲染，车厢在独立 foreground pass 中渲染。这个边界应保留。
- Debug Mode 已新增 F2 硬卧检查面板，可隔离外景、车体、六铺、设备、玻璃、灯光与 HUD；原型选择、固定照明、窗帘状态和观察位对比仍待后续补齐。

## 目标架构

```text
app/src/engine/three/interior/
  CarriageInterior.ts          # 只编排原型、生命周期和 foreground group
  CarriageTypes.ts             # 原型、状态与公共契约
  layouts/
    OpenHardSleeper.ts         # 第一阶段：中国长途开放硬卧
    SleeperCompartment.ts      # 后续：复兴号式现代动卧包厢
    ObservationSoftSeat.ts     # 后续：中国观景软座
    ObservationLounge.ts       # 后续：旅游列车展望空间
  shell/
    CarriageShell.ts           # 断面、墙顶、地板、端墙和窗口节距
    WindowModule.ts            # 窗框、胶条、窗台、帘轨和窗帘
  furniture/
    SeatBay.ts                 # 座椅、桌面、电源与对应窗口
  materials/
    CarriagePalette.ts         # 明确的材质/颜色/粗糙度配置
    CarriageTextures.ts        # 可复用程序化纹理与统一销毁
  lighting/
    CarriageLighting.ts        # 日间补光、夜间间接光与阅读灯
  glass/
    WindowGlass.ts             # 反射、雨滴、雾化和遮光状态
  hud/
    WindowHudSurface.ts        # 现有物理 HUD 与点击投影契约
```

`ThreeCanvas` 继续只持有一个 `CarriageInterior`，并保持外景/车厢双 pass。车厢布局以数据和组合模块表达，但不为了“通用”牺牲各车型的真实结构。

## 实施顺序

### Phase 0：先扩展 Debug Mode（首版已完成）

在改几何前加入可见的车厢调试面板，至少可以：

- 首版已经可以用 F2 或 `?debugCarriage=1` 打开硬卧检查面板，逐组切换外景、车体、六铺、设备、玻璃、灯光和 HUD，并提供“只看车厢 / 全部恢复”。
- 后续补充 `hard-sleeper / soft-seat / sleeper-compartment / observation-lounge` 原型选择；未实现原型显示占位状态，不伪装完成。
- 固定观察位：中心窗、面对面座席、沿车厢看向端门。
- 固定车内光照：日间、傍晚、夜间、隧道。
- 切换外景、座椅、桌面、窗框、玻璃、反射、HUD、灯具与窗帘。
- 固定窗状态：清洁、雨滴、雾化、遮光帘。
- 在同一视口快速切换 16:9 与竖屏安全框。

### Phase 1：拆分现有功能，不改变画面

- 把玻璃、HUD、程序化纹理和通用销毁从 `WindowFrame.ts` 拆出。
- 保留现有截图作为迁移基线；只证明架构拆分没有改变外观和交互。
- 保留 `WindowHudReadout`、控制命中区和 foreground pass 契约。

### Phase 2：完善中国长途开放硬卧

- 首版已经建立窗口对应开放六铺、三层铺位、窗下小桌、护栏/踏板、铺位灯/设备、传统窗帘，以及米色结构、酒红铺垫边和白色卧具的材质层级。
- 下一步先校准车体断面、铺位长度/层距、通道宽度和相机眼位，再补端部行李架、铺号系统、使用痕迹与日夜照明状态。
- HUD 不再像悬浮大屏覆盖窗景；优先落在桌边小屏、窗下窄信息条或独立可关闭层，具体位置通过 Debug Mode 对比决定。
- 不加入乘客模型；先把无人车厢的空间、光线、反射和使用痕迹做好。

### Phase 3：建立窗景切片系统

把路线段从单一 biome 扩展为以下组合字段：

```ts
type WindowScenerySlice = {
  landform: 'plain' | 'rolling-grassland' | 'plateau' | 'gobi' | 'oasis'
  landUse: 'cropland' | 'pasture' | 'sparse' | 'shelterbelt'
  distantProfile: 'tree-line' | 'low-hills' | 'snow-range' | 'flat-horizon'
  railwayInfrastructure: 'dense' | 'normal' | 'sparse'
  atmosphere: 'clear' | 'haze' | 'cold-overcast' | 'dry-glare'
}
```

首批切片以视频中已核查的东北农田、锡林郭勒草原、高原雪山、河西灰色荒漠和南疆绿洲为准。

### Phase 4：增加独立车厢原型

- `SleeperCompartment`：依据 CR400AF-AE，重点验证包厢夜间照明、铺位尺度、遮光和私密性。
- `ObservationSoftSeat`：依据西子号与星光燕赵号座席车，重点验证高背座椅、桌面使用尺度和明亮开放的取景。
- `ObservationLounge`：依据星光燕赵号展望车，重点验证连续观景面、窗间灯具和自由活动空间。
- 每个原型必须有自己的 Debug Mode 入口和视觉核查矩阵。

## 视觉验收矩阵

每次车厢变更只做浏览器视觉检查，并明确记录：

| 维度 | 必查状态 |
| --- | --- |
| 视口 | 桌面 16:9、窄桌面、手机竖屏 |
| 观察位 | 中心窗、左/右转头、沿车厢方向 |
| 光线 | 日间、夜间、隧道、窗外高亮逆光 |
| 玻璃 | 清洁、雨滴、暗景反射、窗帘/遮光 |
| 外景 | 农田、草原、高原雪山、戈壁、绿洲 |
| 功能 | HUD 显示/关闭、控制命中、暂停、复位视角 |

## 非目标

- 不在第一阶段同时重写地形、相机、旅程状态机或音频。
- 不直接复制视频中的品牌标识、纹样或具体列车涂装。
- 不把三种车型混成一个“豪华中国风”车厢。
- 不用更多小物件掩盖空间尺度、窗口节距或光照不成立的问题。

## 已确认的产品选择

第一套车厢采用普通中国长途开放硬卧，重点是普适、可信、适合长时间观看的乘客视角；不以豪华动卧包厢或旅游观光车替代它。软座、豪华动卧与展望车均保留为后续独立原型，而不是通过换色模拟。
