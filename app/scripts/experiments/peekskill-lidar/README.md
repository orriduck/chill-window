# USGS Peekskill source roof-point probe

This cloud experiment downloads one officially catalogued 2022 LAZ tile (about 10.8MB) covering three existing OSM sample buildings, including Mount Saint Francis Church. The catalogue query and actual OSM polygons are archived in `source-selection.json`. It checks the delivered source size, records its actual SHA, reads the declared CRS, and preserves class-6 points within the actual source footprints. Nearby class-2 ground observations are reported separately. No roof, local datum, metre unit, floor count, or height is invented.

The point cloud predates the current OSM snapshot. Publication date and survey year must remain distinct; read the declared source vertical CRS before converting z or comparing it with the runtime DEM. Missing classified building points are a result, not a reason to fall back to guessed roof geometry. This is not runtime integration or an accepted roof mesh.

The first actual probe succeeded and found no class-6 points in the tile. Source WKT declares NAD83(2011)/UTM18N plus NAVD88/GEOID18, all in metres; the survey title is 2022 and publication date is 2024-09-23. A subsequent probe preserves class-1 samples inside the existing footprints with return-number fields for further analysis, explicitly labelled unclassified. Footprint containment alone does not establish that a point belongs to a roof rather than vegetation; raw observations are not a fitted building mesh.

Run heavy download/decompression only in the dedicated Actions workflow. Outputs preserve small source-coordinate JSON subsets and the full metadata/classification report; the complete LAZ is not committed. Main sources: [USGS LiDAR Explorer](https://www.usgs.gov/tools/lidarexplorer), [USGS point-cloud explanation](https://www.usgs.gov/faqs/what-lidar-data-and-where-can-i-download-it), the exact official LAZ URL/catalogue entry in the selection manifest, and [laspy classification/chunk examples](https://laspy.readthedocs.io/en/latest/examples.html).
